# Codebook: `EUframes_person_sim.csv`

**This file is simulated.** No Eurobarometer respondent appears in it, no GESIS
file was read to produce it, and nothing in it should be used for substantive
inference about EU framing. It exists for teaching: a person-level dataset with
a known, named data-generating process, built for the simulation module of the
workshop "Applied Replication for Data Skills".

## Construction

The file is generated by `companion/_model-outputs/simulate_person_twin.R`
(fixed seed 20260727) as a parametric simulation from disclosed aggregate
parameters only. The data-generating process is the three-level random-intercept
model taught in the statistical-methods module – person inside country-year
inside country – run forwards:

cosmo = 0.5526 − 0.005237 × unemp + u_country + u_country-year + e

with u_country ~ N(0, 0.06131²), u_country-year ~ N(0, 0.03853²) and
e ~ N(0, 0.36806²). All five constants are transcribed from the captured
teaching fit `companion/_model-outputs/lmer_3lvl.txt`, a single model fitted
once, locally, to the real GESIS-derived person-level file; only these
aggregate parameters travel into the simulation. The latent outcome is clipped
to the [0, 1] scale bounds (about 18% of draws), so the observed-scale slope
is attenuated by a factor of roughly 0.84 relative to the named −0.005237 –
the generator's validation report quantifies this, and the module teaches why
bounded outcomes do that to linear slopes.

Cell structure and the macro variables (`unemp`, `growth`, `bailout`) are
carried over from the public country-year panel `EUframes_cy.csv`: one cell
per country-year (27 countries × 10 years), with the simulated cell size set
to 5% of the real cell's respondent count (range 25–181; 20,829 rows in
total).

**Demographics and the weight are stylised and carry no information.** `age`,
`female`, `edu4` and `w1` are drawn from plausible marginal distributions,
independent of the outcome and of each other by construction. Any association
between them and `cosmo` in this file is sampling noise. Do not read
demographic 'effects' out of this dataset; that is part of what the module
teaches you to check.

## Variables

| Variable | Description |
|------------------------------------|------------------------------------|
| `pid` | Simulated person identifier (row number) |
| `cntry` | ISO 3166 two-letter code, as in `EUframes_cy.csv` |
| `year` | Year (2004–2013) |
| `w1` | Simulated design-style weight: trimmed lognormal, normalised to mean 1 within country-year |
| `age` | Simulated age, truncated normal, 15–98 |
| `female` | Simulated indicator, P(female) = 0.55 |
| `edu4` | Simulated education band (`le15` / `e16_19` / `e20plus` / `studying`), fixed shares 0.30 / 0.35 / 0.28 / 0.07 |
| `cosmo` | Simulated cosmopolitan framing score on [0, 1]; generated by the DGP above, rounded to 4 decimals |
| `unemp` | Unemployment, % of labour force – real value, joined from `EUframes_cy.csv` |
| `growth` | GDP growth, annual % – real value, joined from `EUframes_cy.csv` |
| `bailout` | EU/IMF assistance-programme indicator – real value, joined from `EUframes_cy.csv` |

The macro variables are real published aggregates (World Bank / European
Commission, via the public panel); everything at person level is synthetic.
